# Bible Trivia Game - Quick Start

## 🚀 Getting Started in 3 Steps

### 1. Install Dependencies
```bash
cd bible-trivia-game
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The app will open at `http://localhost:5173`

### 3. Play!
- Choose a game mode from the menu
- Follow the on-screen instructions
- Try to get the highest score!

## 🎮 Game Modes

### 📖 Guess the Book
1. Read the Bible passage
2. Type the book name (e.g., "John", "Genesis")
3. Press Enter or click Submit
4. Use hints if needed (💡 button)

**Tip:** Try to guess on the first attempt for bonus points!

### 👤 Guess the Person
1. Ask yes/no questions about the Biblical figure
2. Click "Ready to Guess!" when you think you know
3. Enter the person's name
4. Submit your answer

**Tip:** Ask about gender and testament first to narrow down options!

## 📊 Scoring

- **Guess the Book**: Up to 150 points per round
- **Guess the Person**: Up to 240 points per round
- Hints cost 20 points each
- Wrong attempts cost 10 points each

## 🎯 Tips for High Scores

1. **Read carefully** - Look for names, places, and themes
2. **Use hints wisely** - Save them until you really need them
3. **Ask smart questions** - Start broad, then get specific
4. **Learn as you play** - The game teaches you about the Bible

## 🏗️ Build for Production

```bash
npm run build
```

Output goes to the `dist/` folder.

## 🧪 Verify Data

```bash
node verify-data.js
```
