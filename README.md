### 2. Bible Trivia Game
A complete React-based Bible trivia game with two game modes, scoring system, and hints.

**Location:** `/bible-trivia-game/`

**Features:**
- 📖 Guess the Book mode - Identify Bible passages
- 👤 Guess the Person mode - Yes/No question game with Biblical figures
- 🎯 Advanced scoring system with bonuses and penalties
- 💡 Hint system (3 hints per game)
- 📱 Fully responsive design (mobile, tablet, desktop)
- ✨ 35+ Biblical figures and 30+ Bible passages

**Quick Start:**
```bash
cd bible-trivia-game
npm install
npm run dev
```

See the [Bible Trivia Game README](./bible-trivia-game/README.md) for full documentation.
